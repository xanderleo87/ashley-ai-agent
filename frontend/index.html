Process

How Ashley Works

From your message to completed action — here's the flow.

1

You Send a Message

Send a text or voice message to Ashley's Telegram bot. Voice messages are automatically transcribed using OpenAI Whisper.

2

Ashley's Brain Processes

The AI Agent (powered by OpenAI GPT) analyzes your request with full context — current date/time, your contacts, calendar, and conversation history via window buffer memory.

3

Tools Are Executed Sequentially

Ashley calls the right tools one by one: looks up contacts, checks calendar for conflicts, drafts emails, creates events. No parallel execution — strict sequential order for reliability.

4

Confirmation Before Action

Ashley shows you drafts and proposed times. She only proceeds once you say "Go ahead." Conflicts are flagged, never overridden.

5

Response via Text + Voice

Ashley replies with a text summary and a voice note generated by OpenAI TTS (Nova voice) — a complete, human-like conversational experience on Telegram.
